## CoC Semi-Annual Performance README

Two warehouse reports, CoC Mid-Year Performance and CoC End of Year Performance. Each runs APR and CE APR sub-reports per project type for one CoC and summarizes them.

See `docs/features/warehouse/coc-semi-annual-performance.md` for how the reports run, the row definitions in `config/rows.yml`, drill-down access rules, archival, and the Continuum/CoC naming.
